# 2 — Launch lists (OUTPUT)

Save the `launch-catalog.csv` files the **dashboard** generates into this folder.

- In the dashboard, click **Download launch list**. The browser saves it to your
  Downloads folder — move it here (or use Save As and point it here).
- Name them by date, e.g. `launch-catalog-2026-09-26.csv`.

This is the ONLY file that should ever go to Shopify / the CJ app — 30 core products
plus a few extras, already screened for niche fit, margin, and US shipping.
