# 1 — CJ downloads (INPUT)

Save the CSV files you export from CJdropshipping (or TopDawg) into this folder.

- In CJ, export the **CSV** (not the giant Excel workbook — the .xlsx can be hundreds of MB).
- Filter to **US warehouse** in CJ first if the CJ screen allows it.
- Name them by date so you can tell them apart, e.g. `cj-us-2026-09-26.csv`.

Then open the dashboard and click **Import CSV** and pick the file from this folder.
